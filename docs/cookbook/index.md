# FusionRouter Routing Cookbook

## Practical Routing Recipes

- **Recipe 1: High-Performance Coding Prompts**
  Lower intent into `ExecutionProfile::Coding` targeting high-capability code generation models.

- **Recipe 2: Local-Only Offline Routing**
  Route 100% of prompts to local Ollama and LM Studio endpoints without external network requests.

- **Recipe 3: Strict Budget Policy Caps**
  Enforce max cost per request ($0.005) with automatic fallback to cost-optimized providers.

- **Recipe 4: Vision & Multimodal Processing**
  Filter provider selection to candidates advertising `Vision` and `ImageInput` capabilities.
