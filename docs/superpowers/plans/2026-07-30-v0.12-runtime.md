# Capability Runtime Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the Capability Runtime subsystem — sandboxed WASM execution of capability WebAssembly modules via `SandboxRuntime`/`SandboxInstance` traits, `RuntimeModuleCache`, `WasmtimeSandboxRuntime`, and `SandboxConfig`.

**Architecture:** The runtime provides two abstract traits (`SandboxRuntime`, `SandboxInstance`) and one concrete implementation (`WasmtimeSandboxRuntime`). A `RuntimeModuleCache` caches compiled wasmtime modules keyed by `(CapabilityId, Version)`. Instances are ephemeral — each `instantiate` call creates a fresh instance. `RuntimeContext` carries execution metadata (`execution_id`, `host_services`, `deadline`, `telemetry`). `SandboxConfig` controls memory limit, fuel, and timeout. The module is conditionally compiled behind the `wasm-plugins` feature flag for wasmtime-dependent components; the abstract traits and context types compile unconditionally.

**Tech Stack:** wasmtime 0.47 (Cranelift), tokio, async-trait, uuid, semver, parking_lot, thiserror, serde, fusion-plugin-api

## Global Constraints

The following invariants from the spec are enforced at the runtime layer:
1. **Sandbox isolation.** Capability WASM modules have no access to the host system except through declared `CapabilityHostServices` imports.
2. **Deterministic instance creation.** Identical `SandboxRuntime::instantiate(module_bytes, ctx)` with identical `RuntimeContext` produces functionally identical instances.
3. **Ephemeral instances.** Instances are not reused across executions. Each invocation gets a fresh instantiation.
4. **Fair resource accounting.** Memory and fuel limits are enforced per-instance, not per-module.
5. All sandbox interactions go through `CapabilityHostServices` — capabilities never access FusionRouter internals.
6. The existing `src/wasm/` module is NOT modified — new runtime complements it.
7. wasmtime-dependent code is gated behind `#[cfg(feature = "wasm-plugins")]`.
8. `cargo check --no-default-features --lib` must pass without wasmtime.
9. All existing tests (852+ in CI) must continue to pass.
10. The old C-ABI plugin system is not modified.

```rust
use std::collections::HashMap;
use parking_lot::RwLock;
use semver::Version;
use wasmtime::{Engine, Module};
use fusion_plugin_api::CapabilityId;
use crate::runtime::RuntimeError;

type CacheKey = (CapabilityId, Version);

pub struct RuntimeModuleCache {
    modules: RwLock<HashMap<CacheKey, Module>>,
}

impl RuntimeModuleCache {
    pub fn new() -> Self {
        Self {
            modules: RwLock::new(HashMap::new()),
        }
    }

    pub fn get_or_compile(
        &self,
        key: &CacheKey,
        engine: &Engine,
        bytes: &[u8],
    ) -> Result<Module, RuntimeError> {
        {
            let guard = self.modules.read();
            if let Some(module) = guard.get(key) {
                return Ok(module.clone());
            }
        }

        let module = Module::new(engine, bytes)
            .map_err(|e| RuntimeError::CompilationFailed(e.to_string()))?;

        {
            let mut guard = self.modules.write();
            guard.insert(key.clone(), module.clone());
        }

        Ok(module)
    }

    pub fn evict(&self, key: &CacheKey) {
        let mut guard = self.modules.write();
        guard.remove(key);
    }

    pub fn clear(&self) {
        let mut guard = self.modules.write();
        guard.clear();
    }
}

impl Default for RuntimeModuleCache {
    fn default() -> Self {
        Self::new()
    }
}
```

```rust
use std::sync::Arc;
use async_trait::async_trait;
use wasmtime::{Config, Engine, Instance, Linker, Module, Store, Val};
use crate::runtime::config::SandboxConfig;
use crate::runtime::context::RuntimeContext;
use crate::runtime::module_cache::RuntimeModuleCache;
use crate::runtime::sandbox_instance::SandboxInstance;
use crate::runtime::sandbox_runtime::SandboxRuntime;
use crate::runtime::RuntimeError;

pub struct WasmtimeSandboxRuntime {
    engine: Engine,
    module_cache: Arc<RuntimeModuleCache>,
    config: SandboxConfig,
}

impl WasmtimeSandboxRuntime {
    pub fn new(
        config: SandboxConfig,
        module_cache: Arc<RuntimeModuleCache>,
    ) -> Result<Self, RuntimeError> {
        let mut wasm_config = Config::new();
        wasm_config.wasm_reference_types(true);
        wasm_config.wasm_bulk_memory(true);
        wasm_config.consume_fuel(true);
        wasm_config.max_memory_size(config.memory_limit_bytes as usize);

        let engine = Engine::new(&wasm_config)
            .map_err(|e| RuntimeError::CompilationFailed(e.to_string()))?;

        Ok(Self {
            engine,
            module_cache,
            config,
        })
    }
}

#[async_trait]
impl SandboxRuntime for WasmtimeSandboxRuntime {
    fn name(&self) -> &'static str {
        "wasmtime-sandbox"
    }

    async fn instantiate(
        &self,
        module_bytes: &[u8],
        ctx: RuntimeContext,
    ) -> Result<Box<dyn SandboxInstance>, RuntimeError> {
        let key = (
            fusion_plugin_api::CapabilityId::new("anonymous"),
            semver::Version::new(0, 1, 0),
        );

        let module = self
            .module_cache
            .get_or_compile(&key, &self.engine, module_bytes)?;

        let linker = Linker::new(&self.engine);
        let mut store = Store::new(&self.engine, ());
        store
            .set_fuel(self.config.fuel_amount)
            .map_err(|e| RuntimeError::CompilationFailed(e.to_string()))?;

        let instance = linker
            .instantiate(&mut store, &module)
            .map_err(|e| RuntimeError::ExecutionTrap {
                message: e.to_string(),
            })?;

        // Track initial fuel for fuel_consumed()
        let initial_fuel = store.get_fuel().unwrap_or(self.config.fuel_amount);

        Ok(Box::new(WasmtimeSandboxInstance {
            instance,
            store,
            initial_fuel,
        }))
    }
}

pub struct WasmtimeSandboxInstance {
    instance: Instance,
    store: Store<()>,
    initial_fuel: u64,
}

#[async_trait]
impl SandboxInstance for WasmtimeSandboxInstance {
    async fn invoke(&mut self, input: &[u8]) -> Result<Vec<u8>, RuntimeError> {
        let memory = self
            .instance
            .get_memory(&mut self.store, "memory")
            .ok_or_else(|| RuntimeError::ExecutionTrap {
                message: "module does not export 'memory'".into(),
            })?;

        let allocate = self
            .instance
            .get_func(&mut self.store, "allocate")
            .ok_or_else(|| RuntimeError::ExecutionTrap {
                message: "module does not export 'allocate'".into(),
            })?;

        let mut ptr_result = [Val::I32(0)];
        allocate
            .call(&mut self.store, &[Val::I32(input.len() as i32)], &mut ptr_result)
            .map_err(|e| map_trap_error(e))?;
        let ptr = match ptr_result[0] {
            Val::I32(p) => p as usize,
            _ => {
                return Err(RuntimeError::ExecutionTrap {
                    message: "allocate returned non-i32".into(),
                })
            }
        };

        memory
            .write(&mut self.store, ptr, input)
            .map_err(|e| RuntimeError::ExecutionTrap {
                message: format!("memory write failed: {e}"),
            })?;

        let invoke_fn = self
            .instance
            .get_func(&mut self.store, "capability_invoke")
            .ok_or_else(|| RuntimeError::ExecutionTrap {
                message: "module does not export 'capability_invoke'".into(),
            })?;

        let mut result_vals = [Val::I32(0), Val::I32(0)];
        invoke_fn
            .call(
                &mut self.store,
                &[Val::I32(ptr as i32), Val::I32(input.len() as i32)],
                &mut result_vals,
            )
            .map_err(|e| map_trap_error(e))?;

        let result_ptr = match result_vals[0] {
            Val::I32(p) => p as usize,
            _ => {
                return Err(RuntimeError::ExecutionTrap {
                    message: "capability_invoke returned non-i32 for ptr".into(),
                })
            }
        };
        let result_len = match result_vals[1] {
            Val::I32(l) => l as usize,
            _ => {
                return Err(RuntimeError::ExecutionTrap {
                    message: "capability_invoke returned non-i32 for len".into(),
                })
            }
        };

        let mut output = vec![0u8; result_len];
        memory
            .read(&mut self.store, result_ptr, &mut output)
            .map_err(|e| RuntimeError::ExecutionTrap {
                message: format!("memory read failed: {e}"),
            })?;

        Ok(output)
    }

    fn reset(&mut self) -> Result<(), RuntimeError> {
        Err(RuntimeError::NotSupported(
            "reset is not supported in v0.12".into(),
        ))
    }

    fn memory_usage(&self) -> u64 {
        self.instance
            .get_memory(&self.store, "memory")
            .map(|m| m.size(&self.store) as u64 * 65536) // pages * 64KB
            .unwrap_or(0)
    }

    fn fuel_consumed(&self) -> u64 {
        self.store
            .get_fuel()
            .map(|remaining| self.initial_fuel.saturating_sub(remaining))
            .unwrap_or(0)
    }
}

fn map_trap_error(err: wasmtime::Error) -> RuntimeError {
    let err_str = err.to_string();
    if err_str.contains("fuel") || err_str.contains("fuel exhausted") {
        return RuntimeError::FuelExhausted;
    }
    if err_str.contains("out of memory") || err_str.contains("memory") {
        return RuntimeError::OutOfMemory;
    }
    RuntimeError::ExecutionTrap {
        message: err_str,
    }
}
```
