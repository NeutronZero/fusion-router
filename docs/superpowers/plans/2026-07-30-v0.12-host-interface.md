# Host Interface Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the 5-method `CapabilityHostServices` trait, `WasmtimeCapabilityHost` concrete impl, permission-checking helpers, and wasmtime linker setup — the Host Interface subsystem of FusionRouter v0.12.

**Architecture:** Two-layer design: abstract `CapabilityHostServices` trait (ADR-019) → concrete `WasmtimeCapabilityHost` that wires services to WASM imports via a wasmtime `Linker`. Permission gating is enforced at the host level against the capability's `CapabilityContract.permissions`.

**Tech Stack:** Rust, wasmtime 0.47 (optional feature `wasm-plugins`), tokio, `reqwest`, `tracing`, `fusion-plugin-api` (workspace crate).

## Global Constraints

- All new code is gated behind `#[cfg(feature = "wasm-plugins")]` where it depends on wasmtime.
- `capability` subsystem types (`CapabilityRegistry`, `InMemoryCapabilityRegistry`) are frozen — no structural changes.
- `CapabilityContract` and `Permission` live in `fusion-plugin-api` workspace crate — import via `fusion_plugin_api::*`.
- `GateError` is extended with a `PermissionDenied` variant (host-level errors, distinct from release-gate errors).
- All sandbox interactions go through `CapabilityHostServices` — capabilities never access FusionRouter internals.
- Zero warnings: remove dead code, unused imports, unreferenced parameters immediately.
- wasmtime = "47", reqwest = "0.11", tracing = "0.1".
- Tests are `#[cfg(test)]` inline in source files, plus integration tests in `tests/host_tests.rs`.

```rust
use fusion_plugin_api::Permission;
use crate::release::gate::GateError;

pub fn check_secret_access(permissions: &[Permission], secret_name: &str) -> Result<(), GateError> {
    for perm in permissions {
        match perm {
            Permission::Secrets(pattern) => {
                if glob_match(pattern, secret_name) {
                    return Ok(());
                }
            }
            _ => continue,
        }
    }
    Err(GateError::PermissionDenied(format!(
        "secret '{}' is not in the declared permission set", secret_name
    )))
}

pub fn check_http_access(permissions: &[Permission], url: &str) -> Result<(), GateError> {
    for perm in permissions {
        match perm {
            Permission::Http(pattern) => {
                if glob_match(pattern, url) {
                    return Ok(());
                }
            }
            _ => continue,
        }
    }
    Err(GateError::PermissionDenied(format!(
        "URL '{}' is not in the declared permission set", url
    )))
}

fn glob_match(pattern: &str, candidate: &str) -> bool {
    if pattern == candidate {
        return true;
    }
    if let Some(prefix) = pattern.strip_suffix('*') {
        return candidate.starts_with(prefix);
    }
    false
}
```

```rust
    execution_id: Uuid,

impl WasmtimeCapabilityHost {
    pub fn new(
        registry: Arc<dyn CapabilityRegistry>,
        event_bus: Arc<dyn EventBus>,
        http_client: reqwest::Client,
        metrics: Arc<FusionMetrics>,
        execution_id: Uuid,

        correlation_id: Option<String>,
    ) -> Self {

            http_client,

            workflow_id,

        }

#[async_trait]
impl CapabilityHostServices for WasmtimeCapabilityHost {
    async fn emit_event(&self, event: ExecutionEvent) -> Result<(), GateError> {
        let envelope = ExecutionEventEnvelope::new(
            self.workflow_id.to_string(),
            self.execution_id.to_string(),
            self.correlation_id.clone(),
            0,
            None,
            event,
        );
        self.event_bus.publish(envelope).await
    }

    async fn log(&self, level: Level, message: &str) {
        tracing::event!(level, "capability: {}", message);
    }

    async fn fetch_secret(&self, secret_name: &str) -> Result<String, GateError> {
        let contract = self.registry
            .list()
            .into_iter()
            .find(|c| {
                c.permissions.iter().any(|p| matches!(p, fusion_plugin_api::Permission::Secrets(_)))
            })
            .ok_or_else(|| GateError::PermissionDenied("no capability with secret permissions".into()))?;
        check_secret_access(&contract.permissions, secret_name)?;
        // For v0.12 secrets are resolved via environment variables named after the secret
        std::env::var(secret_name)
            .map_err(|_| GateError::PermissionDenied(format!("secret '{}' not found in environment", secret_name)))
    }

    async fn http_request(&self, req: Request) -> Result<reqwest::Response, GateError> {
        let url_str = req.url().to_string();
        let contract = self.registry
            .list()
            .into_iter()
            .find(|c| {
                c.permissions.iter().any(|p| matches!(p, fusion_plugin_api::Permission::Http(_)))
            })
            .ok_or_else(|| GateError::PermissionDenied("no capability with HTTP permissions".into()))?;
        check_http_access(&contract.permissions, &url_str)?;
        self.http_client.execute(req).await
            .map_err(|e| GateError::ExecutionFailed(format!("HTTP request failed: {e}")))
    }

    fn record_metric(&self, name: &str, value: f64) {
        tracing::info!(metric_name = name, metric_value = value, "capability metric");
        self.metrics.requests_total.inc_by(value as u64);
    }
}
```
