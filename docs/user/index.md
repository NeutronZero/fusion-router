# FusionRouter User Guide

Welcome to **FusionRouter**, the compiler-driven AI orchestration platform.

## Getting Started in 5 Minutes

1. **Launch FusionRouter:** Run `fusion-server` or click the desktop application icon.
2. **Open Fusion Studio:** Navigate your browser to `http://localhost:8080`.
3. **First-Run Setup Wizard:**
   - Select your primary provider (OpenRouter, Anthropic, OpenAI, or Ollama).
   - Enter your API Key credentials (encrypted via AES-256-GCM).
   - Test Connection to verify latency.
   - Auto-discover local models (Ollama on `11434`, LM Studio on `1234`).
4. **Send Your First Verification Chat Prompt:** Chat directly with compiler-driven routing transparency.

## Fusion Studio Features
- **Provider Management:** Hot-reload keys and settings without server restart.
- **Compiler Inspector:** Click any chat message to open the 5-Tab Compiler Inspector and view why providers were selected.
- **Mission Control Dashboard:** View live executions, daily costs, and system status.
